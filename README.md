# sorted-index-finder

**This function determines the correct position to insert a number into an array after sorting it in ascending order.

How it works

The array is sorted from smallest to biggest.

The function finds the first value that is greater than or equal to the number.

If none are greater, the number belongs at the end.

Example Behavior

Insert 1.5 into [1, 2, 3, 4] → position 1

Insert 19 into [20, 3, 5] (sorted → [3, 5, 20]) → position 2

Insert 20 into [5, 10, 15] → position 3

Purpose

Useful for:

Maintaining sorted lists

Ranking systems**
